# 🎯 ResumeAI — Smart Resume Analyzer & Live Job Matcher

An AI-powered Resume Analysis and Job Recommendation System built using Python, Streamlit, Machine Learning, SQLite, and the JSearch API.

Upload your resume → Detect skills automatically → Identify your engineering domain → Select your preferred role → Get real-time job opportunities from India's top job platforms.

## 📌 Project Overview

ResumeAI helps students, freshers, and job seekers quickly analyze resumes and discover relevant job opportunities.

The system automatically:

* Parses PDF and DOCX resumes
* Extracts technical skills
* Detects engineering domain
* Recommends suitable job roles
* Fetches live job listings
* Provides direct application links

---

## ✨ Features

### 📄 Resume Parsing

* Supports PDF and DOCX files
* Extracts text from paragraphs and tables
* Automatic skill detection

### 🧠 Skill Detection Engine

* Detects 150+ technical skills
* Covers multiple engineering domains
* Identifies candidate specialization automatically

### 💼 Smart Job Matching

* KNN-based recommendation system
* Skill-based matching logic
* Personalized job suggestions

### 🔴 Live Job Search

* Real-time jobs from JSearch API
* LinkedIn, Indeed, Glassdoor and other sources
* Direct Apply Now links

### 🎨 Professional UI

* Modern dark theme
* Responsive Streamlit interface
* Interactive job cards

### 🗄️ Database Support

* SQLite integration
* Stores jobs and analysis data
